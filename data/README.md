# Fonte e Descrição dos Dados — SMS Spam Collection

- **Título do dataset:** SMS Spam Collection Dataset
- **Instituição / Autores originais:** Tiago A. Almeida & José María Gómez Hidalgo (UCI Machine Learning Repository) / espelhado no Kaggle por *UCI Machine Learning*
- **URL de acesso:** https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset
- **Data de acesso:** 24/11/2026
- **Licença / Condições de uso:** Base pública amplamente utilizada para pesquisa acadêmica e educacional (listada como *Unknown* na ficha do Kaggle; original disponível no UCI Machine Learning Repository).
- **Tamanho aproximado:** 5.574 registros brutos (5.158 mensagens únicas válidas após remoção de duplicatas e entradas vazias).
- **Descrição das colunas:**
  - 1 (renomeada no pré-processamento para label): variável-alvo categórica indicando se a mensagem é legítima (ham) ou indesejada (spam).
  - 2 (renomeada no pré-processamento para message): texto bruto da mensagem SMS em inglês.
- **Como obter:**
  1. Acesse o link do Kaggle acima e baixe o arquivo compactado (archive.zip).
  2. Extraia o arquivo spam.csv e salve-o em data/spam.csv.
